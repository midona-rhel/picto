# Picto 0.6.14-alpha

* More consistent loading times when searching, filtering, and jumping around large libraries.
* Improved browsing responsiveness while new files are being imported.
* Progress messages when switching libraries help explain what is loading.
* More reliable library switching when an earlier operation is interrupted or the app is closing.
* Cancelling the opening of a downloaded cloud library keeps the download available to open again.

Large libraries may take a little longer to open, with more consistent browsing once loaded. The first open after upgrading may take longer while the library is updated.
