# Picto 0.6.1-alpha

Picto 0.6.1-alpha stabilizes subscriptions, gallery imports, authentication, and folder
organization after the 0.6.0-alpha backend rebuild. It replaces the remaining subscription
sidecars with one native Rust execution path and adds an explicit upgrade for 0.6.0-alpha
libraries.

This remains an alpha release. Picto creates a database backup before the supported schema upgrade,
but important libraries should still have an independent backup.

## Native subscriptions

- Replaced gallery-dl, OF-Scraper, Python bridges, and provider-owned history databases with native
  Rust providers assembled from shared HTTP, authentication, pagination, media, archive, tag, and
  settlement capabilities.
- Enforced one serial post lifecycle: traverse one post, download its usable media, ingest it,
  settle it as added or skipped, then request the next post.
- Made the per-run limit count successfully added posts rather than traversed posts or media files.
- Persisted post, file, and root attempts so interrupted work can resume idempotently without
  erasing completed gallery progress.
- Added a global subscription pause gate that halts active source I/O without overwriting the hold
  state of individual subscriptions or queries.
- Restored continuous gallery progress, single-gallery execution, clear retry/pause/stop states,
  and reuse of already staged files after a pause.
- Kept direct-site Picto-managed login and OS credential storage as the only authentication path.

## Source coverage

- Hardened native extraction, full-quality media selection, metadata normalization, rate limiting,
  and error reporting across the supported booru, creator, account, and gallery sources.
- Added shared archive-feed behavior used by Pawchive.
- Removed Coomer and Kemono from the supported registry because they do not yet have verified native
  implementations. Tumblr remains intentionally unsupported.
- OnlyFans supports purchases, messages, timeline, archived, and pinned partitions. Authenticated
  coverage for every partition and Widevine-protected media remains tracked separately.

## Library compatibility

- Added a named migration from `picto-library-schema-1-2026-08-29-fts-substring` to
  `picto-library-schema-1-2026-08-30-native-sources`.
- The migration creates a consistent SQLite backup beside the library, runs in one transaction,
  validates required columns and foreign keys, and preserves existing library and source data.
- Unknown schema fingerprints fail without mutation instead of receiving a guessed conversion.

## Folder organization and interface

- Folder and smart-folder drag-and-drop now moves all selected top-level folders, including
  siblings from the same parent and selections from different parents.
- Same-parent drops reorder correctly, selected child folders follow their selected parent once,
  and drops into a selected subtree are rejected.
- Bulk context-menu moves use the same serialized tree operation rather than racing independent
  moves.
- Subscription tables, gallery actions, progress presentation, and overflow handling are more
  consistent and accessible.
- Only the main window uses the destructive red close-button hover; dialogs and utility windows use
  the normal neutral control highlight.

## Cleanup and verification

- Removed the obsolete source adapters, sidecar runtime paths, temporary development credential
  store, unsupported source fixtures, and superseded provider PBI.
- Release packages contain no Python runtime, gallery-dl, OF-Scraper, provider-owned download
  database, credentials, or development library.
- The release gate covers the complete frontend and Rust test suites, TypeScript, strict Clippy,
  command parity, source and artifact audits, platform packaging, and packaged smoke tests.

## Known deferred work

- Stabilize the active duplicate-review selection while background pairs arrive.
- Apply the canonical smart-name policy when subscription duplicates merge.
- Require at least three characters before deferred substring text search executes.
- Complete authenticated OnlyFans partition coverage and the provisioned DRM-device boundary.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported.
