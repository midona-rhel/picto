# Picto 0.6.21-alpha

* Picto no longer asks "Open this library directly?" before it opens a library.
* After an update from 0.6.19, the library that was open there opens when Picto starts. If 0.6.20 has already run on your computer, choose your library once in the Library Manager; it opens by itself from then on.
* On Windows, the minimise, maximise and close buttons of the window work.
* On Windows and Linux, the mouse wheel scrolls 100 pixels for each notch, as 0.6.19 did, and the movement is smooth. Before, a notch moved 45 pixels in one jump.
* A library that was last opened by an older version of Picto is updated when it is opened, after a backup of its database is made. 0.6.20 refused such a library.
