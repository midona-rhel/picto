# Picto 0.6.20-alpha

* Picto has been rewritten as a native app and no longer uses Electron. It has the same name, installs over the version you have, and opens the same libraries. Your libraries, with their items, tags, folders and settings, are unchanged.
* The first time this version starts, no library opens by itself. Choose your library in the Library Manager. Picto asks once for each library whether it may open it.
* Your site logins and the downloaded AI models are kept.
* The window's size and position, the widths of the sidebar and the inspector, saved filters, recent tags and folders, changed keyboard shortcuts, the language and the interface zoom start from their defaults. Set them again.
* Only one Picto runs at a time. A second Picto that you start while Picto is open ends at once.
* **Quick Search** (`Mod+T` or `Mod+K`) finds folders, tags, items and menu commands from one field.
* The themes that made the whole window translucent are gone. **Settings → General** has a switch that makes the sidebar and the inspector translucent on macOS and Windows.
* Opening a `.picto-pack` file from the file manager does not import it reliably yet. Use **File → Import Picto Pack...** instead.
* Not in this version yet: text selection in PDF files, WOFF2 font previews, images in Markdown files, and remembering the zoom of each image in a detail window.
* On Linux, Picto now needs GTK 3 and WebKitGTK 4.1 from the system. Ubuntu has both. On a system without WebKitGTK 4.1, such as one with the KDE desktop, Picto shows which package to install and does not start until it is installed.
