# Picto User Guide

Picto is a desktop library for images, video and other media. It runs on Windows, macOS and Linux.

In this guide, `Mod` means `Ctrl` on Windows and Linux and `Cmd` on macOS. The complete list of
keyboard shortcuts is in **Settings → Shortcuts**, where you can also change them.

## Start here

- [Getting Started](getting-started.md) says how to install Picto and create the first library.
- [Interface Overview](interface-overview.md) describes the title bar, the sidebar, the grid and the
  inspector.
- [Library Management](library-management.md) says how to create, open, switch, move and delete
  libraries.
