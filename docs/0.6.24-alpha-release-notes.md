# Picto 0.6.24-alpha

* On Windows and Linux, a menu is drawn inside Picto's window again. It has the same blur as on macOS, it grows into place when it opens and it fades when it closes. In 0.6.23 a menu on Windows 11 and on Linux with KDE opened in a window of its own, with the system's blur and without these animations. A menu on Windows and Linux does not reach past the edge of Picto's window. On macOS nothing changed.
* The Library Manager has a button **Merge Libraries…** below the list of libraries. You choose a second library and which of the two is the primary library. Every item, tag, folder, smart folder and collection of both libraries is put into the primary library, and a file that both hold is kept once. Where the two libraries disagree, the primary library's version is used. Nothing is deleted from the other library. Its subscriptions, cloud sync settings and watched folders are not carried over, and a merge cannot be undone with Undo.
* Cloud sync shares deletions between the computers that sync one library. This covers deleting an item or a collection permanently, moving it to the Trash and restoring it from the Trash, and deleting a tag, a folder or a smart folder. When two computers did different things to the same item, the later one wins on both. An item that you import again after it was deleted stays, and so does an item whose file differs from the file that was deleted.
* An item that you import, tag, rate, rename or move into a folder on one computer still does not appear on the others. Only deletions are shared.
* The cloud menu of a library in the Library Manager has an item **Delete Cloud Data…**. It deletes the library's copy in the cloud folder. The library on this computer is not changed. Other computers that sync the library keep their local libraries and stop syncing.
