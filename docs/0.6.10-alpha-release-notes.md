# Picto 0.6.10-alpha

Picto 0.6.10-alpha is a focused Windows media playback and thumbnail reliability release.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Windows media playback

- Serves valid partial-content responses for local media byte-range requests, allowing Chromium to
  seek and play WebM files on Windows instead of rejecting the stream.
- Extends the packaged release smoke test to play an embedded VP9 WebM and prove playback advances
  on macOS, Windows, and Linux before assets are published.

## Flash thumbnails

- Assigns Flash thumbnail generation to Picto's browser renderer rather than repeatedly asking the
  native thumbnail worker to use a backend it does not own.
- Settles browser-owned thumbnail jobs cleanly while preserving the generated thumbnail for normal
  publication and display.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
