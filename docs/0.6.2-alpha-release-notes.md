# Picto 0.6.2-alpha

Picto 0.6.2-alpha is a focused reliability and interface release. It improves cloud-library
discovery, folder organization, subscription metadata, media previews, filtering, localization,
and keyboard operation while keeping the native library and subscription architecture introduced
in 0.6.1-alpha.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Cloud libraries and release delivery

- Recognizes folder-mounted and drive-mounted Google Drive roots across supported desktop layouts,
  including configurations where My Drive and shared folders are exposed differently.
- Tightens cloud-root validation and discovery so configured providers resolve to their actual
  synchronized root instead of accumulating ambiguous locations.
- Reuses downloaded packaging inputs and compiled release work across CI stages, substantially
  reducing redundant release builds.
- Keeps alpha releases eligible for update discovery so existing alpha users can move directly to
  the newest published build.

## Folders and recent activity

- Folder drag-and-drop now preserves selected trees, rejects moves beyond the supported depth, and
  remains responsive on large hierarchies.
- Allows sibling folders to share a name; identity and parentage, not display names, determine the
  folder being moved.
- Recently Viewed updates immediately whenever an item is opened and reorders an item when it is
  viewed again.
- Reserves the library-switcher area while the sidebar loads, preventing the initial sidebar reflow.

## Subscriptions and naming

- Uses one ranked smart-name policy for exact ingestion and duplicate resolution, preserving
  meaningful user and collection names while upgrading weak numeric, hash-like, or generated names.
- Improves provider title and clear-text note extraction while keeping collection names separate
  from member filenames.
- Duplicate undo and redo restore smart-name changes together with the affected media state.

## Media handling

- Restores native Pixiv Ugoira conversion to VP9 WebM using the animation frame timing supplied by
  Pixiv.
- Treats JPEG XL thumbnails consistently in the grid, Detail View, and Quick Look while retaining
  the raster thumbnail until the full image is ready.
- Browser drag-and-drop now fails immediately for unsupported link-only payloads instead of leaving
  the grid in a stuck import state.

## Filters, portals, and localization

- Type filters are additive and stable: multiple concrete formats or broad media families can be
  selected without the menu collapsing after the first choice. Choices remain limited to formats
  present in the initial grid.
- Date filters use the shared calendar picker. Redundant Notes and URL fields were removed because
  the main full-text search already covers them.
- Tag and folder portals now support consistent Tab, arrow-key, and Enter navigation, clearer focus,
  accessible expansion controls, and compact visual key hints.
- Refines color tolerance controls, filter-selection styling, AI tag review controls, and shared
  portal surfaces.
- Expands and corrects interface localization across English, German, Spanish, Portuguese, French,
  Simplified Chinese, Japanese, and Finnish.
- Refreshes the cross-platform `.picto-pack` artwork.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
