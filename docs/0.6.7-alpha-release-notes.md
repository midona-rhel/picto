# Picto 0.6.7-alpha

Picto 0.6.7-alpha repairs cloud-restored library projections and makes thumbnail recovery visible,
progressive, and diagnosable.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Cloud libraries

- Restores missing thumbnail work after an original cloud blob becomes available, including items
  whose earlier thumbnail attempts had already failed.
- Streams completed recovered thumbnails into the open grid instead of requiring a navigation or
  application refresh.
- Repairs incomplete lifecycle and rating projections from a valid checkpoint when opening a
  migrated or cloud-restored library, while avoiding projection writes on healthy opens.

## Grid thumbnails

- Loads a raster thumbnail before upgrading a large tile to its full-resolution original, so a
  transient original-image failure cannot leave an otherwise valid item as a permanent grey tile.
- Keeps the valid thumbnail visible if the full-resolution upgrade fails.
- Records terminal thumbnail failures in Diagnostics with the content hash, requested URL,
  fetch-versus-decode stage, exception message, and retry count.
- Ignores completion events for off-screen thumbnails, preventing large cloud restores from
  causing unnecessary grid redraws.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
