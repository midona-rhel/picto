# Next Picto alpha

## Imports you can keep an eye on

Importing a folder now opens a progress window. It shows when Picto is finding files, how many it has processed, its speed, and an estimate of the time left. Minimize it if you want to keep browsing, then bring it back from the progress bar.

You can pause and resume an import. If you stop it, choose whether to keep the new items or remove them. Removing them leaves items that were already in your library alone. Picto also prevents a second import from starting while one is still open, including when you drop files or import a Picto Pack.

An import that was paused stays paused after a restart. One that was running picks up again.

## Fewer copies, complete collections

The same file no longer needs a separate item every time it appears in a collection. Picto combines collections that share files, so the complete sets stay together rather than leaving smaller collections with missing images.

When you open an older library, Picto backs up the database before combining existing copies. Tags, folder memberships, notes and links carry over, and the highest rating is kept. The first open can take longer while this happens. Keep the backup: an updated library may not open in an older Picto version.

## A second chance after deleting

Permanent deletion can now be undone during the current session, up to the limit you choose in Settings. Larger deletions warn you when they cannot be undone. Once you close Picto, that undo history is gone and the deleted files are cleaned up.

You can also choose whether rejecting an Inbox item sends it to Trash or deletes it permanently. The grid shortcut follows that setting too. Undo and redo messages now say what changed in everyday language.

## Small fixes you'll notice

- Tag searches put exact matches first. Searching for a series is less likely to bury it under character tags.
- Sidebar arrows expand or collapse folders with one click. The context menu can expand a collapsed folder too, and open/closed folders stay that way between sessions.
- Quick Look keeps each image's own proportions as you accept or reject Inbox items. The review buttons stay rounded, and their highlight only appears when pressed.
- Subscription counts show what was imported, even if you later trash or delete those items.
- On macOS, the Dock badge clears when you return to Picto. The app icon also has a larger, unified book design.
