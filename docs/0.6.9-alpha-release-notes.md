# Picto 0.6.9-alpha

Picto 0.6.9-alpha is a focused Windows media and update reliability release. It also repairs
first-load thumbnail publication across all supported platforms.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Windows media and updates

- Keeps grid text rendering synchronized with Chromium's normal paint cycle, preventing transient
  missing or flashing labels while navigating the grid.
- Streams WebM video and audio through Chromium's native file loader and byte-range handling.
- Shows an in-app notification as soon as a new version is available.
- Downloads full Windows installers directly instead of first attempting an unsupported
  differential range request and logging a 501 fallback error.

## Thumbnails

- Renders a missing thumbnail once per file and publishes readiness only after the generated file
  exists, so newly imported media appears without restarting Picto.
- Fits video thumbnails inside their tile without cropping, stretching, or overflowing its edge.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
