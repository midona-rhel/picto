# Picto 0.6.4-alpha

Picto 0.6.4-alpha is a focused reliability release for cloud libraries and multi-item inspection.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Cloud libraries

- Fixes cloud-library joining on SQLite versions that rejected the recovery-queue query.
- Makes retrying a failed cloud join safe by cleaning up only incomplete join remnants while
  preserving existing libraries.
- Replaces raw remote errors with concise, actionable Library Manager messages.
- Makes the Library Manager opaque and visually consistent across macOS, Windows, and Linux.
- Improves separation between cloud providers and discovered cloud libraries.

## Inspector

- Keeps the inspector geometry stable when switching between one item and multiple selected items.
- Presents the multi-selection summary as centered, non-editable text with a bold accent-colored
  count.

## AI tagging

- Clarifies that the minimum-confidence control applies to every image in the review job and keeps
  that job-wide behavior covered by regression tests.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
