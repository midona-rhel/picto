# Picto 0.6.13-alpha

* Improved grid performance, especially in large libraries, with smoother scrolling and faster navigation.
* Jumping to distant parts of your library no longer requires loading everything in between.
* Fixed empty grids when opening smart folders, changing filters, or returning to a previous scroll position.
* Random order loads faster, and no longer shows irrelevant sort-direction controls.
* Folder previews now consistently show the first four items in the current results, wherever you scroll.
* Updating ratings and other unrelated settings no longer slows down your next grid navigation.
