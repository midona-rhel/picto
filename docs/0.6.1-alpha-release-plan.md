# Picto 0.6.1-alpha release plan

## Scope

This alpha stabilizes existing behavior. It does not add a new product surface.

- Ship the native Rust subscription providers and remove the replaced Python/source-sidecar paths.
- Preserve strict serial post settlement, resumable gallery progress, and one global subscription
  pause gate that does not overwrite per-subscription or per-query state.
- Support multi-folder and multi-smart-folder tree moves, including same-parent reordering,
  cross-parent selections, and parent/child selections without duplicate moves.
- Remove unsupported Coomer and Kemono sources until they have a verified native implementation.
- Remove temporary development authentication state; keep direct-site managed login and OS
  credential storage as the only authentication path.

## Library upgrade

- Migrate only `picto-library-schema-1-2026-08-29-fts-substring` to
  `picto-library-schema-1-2026-08-30-native-sources`.
- Create a consistent SQLite backup beside the library before mutation.
- Add the durable source post, file, and root attempt tables in one transaction.
- Validate required columns and foreign keys before commit.
- Preserve media, collections, folders, tags, settings, subscriptions, and source history.
- Reject every unknown fingerprint without changing it.

## Release gates

1. `npm run alpha:verify` passes from a clean worktree.
2. Migration tests prove backup creation, retained data, the exact supported upgrade, and untouched
   rejection of unknown schemas.
3. Folder drag-and-drop tests cover same-parent reordering, selected siblings, mixed parents,
   parent-plus-child selections, and invalid descendant targets.
4. A migrated development library opens and agrees with a fresh library on schema validation.
5. Subscription smoke covers strict post accounting, pause/resume, global pause, gallery progress,
   duplicate settlement, and restart recovery.
6. Source and artifact audits prove no Python runtime, gallery-dl, OF-Scraper, credentials,
   development databases, or generated binaries enter the package.
7. Package and smoke the supported macOS artifact; Windows and Linux remain publication gates in CI.

## Deferred

The active PBIs for duplicate selection stability, subscription merge naming, minimum text-search
length, and remaining OnlyFans coverage are not silently folded into this release. Each either
closes with focused tests and smoke evidence or remains explicitly deferred.
