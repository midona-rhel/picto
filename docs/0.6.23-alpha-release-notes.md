# Picto 0.6.23-alpha

* On Windows 11 and on Linux with KDE, a menu now opens in a window of its own, as it already did on macOS, and can reach past the edge of Picto's window. On other versions of Windows and on other Linux desktops it stays inside the window. Menus are blurred on every system.
* While a video loads, Picto shows the video's first frame, so the picture no longer jumps from the middle of the video to its start. For a video that was already in the library, this starts with the second time you open it.
* On Windows, a library is listed once and its path is shown as, for example, `E:\Main.library`. Before, the same library could be listed twice, once with a path that starts with `\\?\`.
* The Library Manager shows a scroll bar when a library's cards or the list of libraries do not fit in the window.
* The selection rings of folder tiles that are next to each other no longer touch.
* On Linux, Picto's windows are grouped under Picto's icon in the taskbar.
* On Windows, the folder of a library that Picto has opened shows the library icon in Explorer.
* The log window shows how long each video took to open.
