# PBIs

PBIs contain only observed, unfinished release behavior with a finite acceptance test. Completed
and superseded PBIs are deleted; Git history is the archive.

The executable backlog is [`../RELEASE_COMPLETION_PLAN.md`](../RELEASE_COMPLETION_PLAN.md). Current
blockers are indexed in [`active-alpha/README.md`](active-alpha/README.md).
