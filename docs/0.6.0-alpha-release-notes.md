# Picto 0.6.0-alpha

Picto 0.6.0-alpha is a substantial rebuild of the library, import, subscription, collection, and
media-management foundations introduced in 0.5.0-alpha. The release consolidates previously
overlapping code paths into one canonical library model while refining the everyday grid,
inspector, tag, duplicate, and viewer experiences.

This remains an alpha release. Back up important libraries before opening them with this version.

## Highlights

### One consistent library

- Library items are now represented consistently as standalone media or ordered collections.
- Imports, subscriptions, watched folders, retries, and gallery downloads settle through one
  durable ingest path.
- Folder membership, tags, lifecycle state, selection, counts, export, and search now resolve the
  same canonical item set.
- Mutations settle their database and projection changes before the interface is notified, reducing
  stale counts, ghost items, and navigation flicker.
- Exact file hashes reuse physical storage without incorrectly collapsing distinct source posts or
  logical library items.

### Collections and organization

- Create, merge, detach, ungroup, reorder, rename, and choose covers for collections.
- Preserve collection ordering and metadata through undoable operations.
- Import folders with configurable hierarchy preservation, subfolder traversal, and omission of
  folders that contain no supported media. Generic ZIP archives are ignored rather than expanded.
- Copy, paste, drag, drop, export, tag, organize, accept, and reject multi-item selections through
  consistent commands.

### Duplicate review

- Fast perceptual candidate discovery is followed by aligned, localized visual verification.
- Similarity scoring better distinguishes harmless encoding noise from meaningful localized edits.
- Comparison previews remain visible while navigating and transition from thumbnails to full-quality
  media without flashing the workspace background.
- Smart Merge preserves organization and provenance while ranking exact visual matches using
  resolution and encoding fidelity, with deterministic fallbacks when stronger evidence is absent.
- Difference viewing, actual-pixel viewing, fit-to-window controls, and merge actions share a compact
  comparison toolbar.

### Subscriptions and gallery imports

- Subscription runs, source items, downloads, retries, issues, and terminal outcomes are persisted
  and recoverable after restart.
- Progress is reported while work happens instead of appearing only when an entire run finishes.
- Add supported gallery URLs as transient jobs that download completely before a collection is
  ingested atomically.
- Gallery imports report sidecar failures directly, avoid stale archive state, normalize supported
  metadata, and notify when a gallery finishes.
- Query grouping, inbox limits, destinations, run history, source health, and cover selection have
  clearer controls and more efficient reads.

### Local AI tagging

- Download and manage multiple optional tagging models from Settings.
- Selected models execute serially so only one model and runtime need to be resident at a time.
- Batch tagging streams progress and results while images are processed.
- Apple Silicon can build or download Core ML optimizations; other supported paths retain CPU or
  ONNX fallback behavior.
- Model settings show download, optimization, storage, confidence, and relative speed information.
- Tag namespaces emitted by a model are preserved and mapped into Picto's normal tag groups.

### Grid, inspector, tags, and viewers

- Justified and waterfall grids use bounded virtualization and more stable scroll estimation for
  large libraries.
- Compact spacing is stored per view, selection rings reserve their own layout space, and final-row
  items stay within the drawable grid.
- Inspector fields, properties, sources, tags, folders, multi-selection previews, and collection
  metadata have been visually and behaviorally aligned.
- Multi-selection previews keep stable positions, place newer selections above older ones, and fade
  naturally as entries leave the stack.
- Tag Manager supports groups, colors, starring, creation from search, unused-tag cleanup, and
  clearer alphabetical presentation.
- Smart-folder rules have typed editors for ratings, dates, colors, file formats, sizes, dimensions,
  duration, text, and source fields.
- Quick Look and detail views retain the previous image until its replacement is ready, reducing
  blank frames during navigation.

### Performance and diagnostics

- Incremental bitmap projections, targeted smart-folder settlement, indexed range predicates,
  bounded FTS maintenance, and batched ingest reduce work as libraries grow.
- Sidebar, subscription, cloud, and item queries avoid several repeated-read and unbounded-scan
  patterns.
- Thumbnail and derivative work is deduplicated and prioritized, with duplicate settlement triggered
  when perceptual hashes become available.
- The Logs window displays worker state, allows aligned selectable output, and can save a support
  report containing logs, worker state, application version, and host information.

## Supported packages

- macOS on Apple Silicon: DMG and ZIP
- Windows on x86-64: NSIS installer
- Linux on x86-64: AppImage

Intel macOS is not supported by this alpha.

## Alpha notes

- Picto uses the current pre-release library schema. Keep a backup before upgrading; incompatible
  alpha libraries fail without being modified rather than being migrated silently.
- The guided tour is not exposed in this release.
- Optional AI models are downloaded separately and can consume significant temporary resources
  while an Apple Silicon optimization is compiled.
- The macOS alpha uses Picto's private self-signed certificate. Public Apple Developer ID signing
  and notarization are not part of this alpha gate.
- Cloud Sync should be treated as experimental until the final packaged persistence and restart
  smoke for this release candidate is complete.

## Reporting a problem

Open **Logs**, reproduce the problem, then choose **Save support report**. Attach that report with a
short description of what you expected, what happened, and the action that triggered it. Reports
include diagnostic events and worker state but should still be reviewed before sharing.

## Development summary

The release-note review covered 677 product commits after `v0.5.0-alpha`. The largest areas of work
were the library model, core runtime, grid, subscriptions, duplicate review, inspector,
collections, local AI, cloud sync, and search.
