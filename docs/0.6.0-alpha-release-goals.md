Work these goals in order. Keep only one goal active at a time.

1. [x] Remove React test scheduling warnings without suppressing diagnostics.
2. [x] Split the dirty integration surface into coherent, reviewed commits.
3. [ ] Run clean package and smoke CI on macOS ARM64, Windows x64, and Linux x64.
4. [x] Audit packaged licenses, native modules, sidecars, and release artifacts.

6. [x] Produce the macOS icon with the proper Apple material workflow.
