# Picto 0.6.5-alpha

Picto 0.6.5-alpha improves cloud-library recovery, deletion safety, and update discovery.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Cloud recovery

- Shows one compact, byte-accurate progress bar at the bottom of the library while a joined cloud
  library restores its original media.
- Keeps the interface responsive by allowing only one disk-heavy cloud restore or batch-ingestion
  job to run at a time.
- Keeps ordinary one-item subscription ingestion silent; it does not flash the heavy-job bar.

## Deletion and resurrection

- Retains deleted cloud originals for seven days by default, with a configurable retention period
  in Cloud settings.
- Reuses a retained content-addressed blob immediately when a genuinely newer ingestion adds the
  same media again.
- Keeps deletion authoritative over older queued work while allowing a later ingestion to create a
  new add epoch and supersede the tombstone.
- Purges an expired physical cloud blob only when no live library item references it, while keeping
  the logical tombstone available for offline peers.
- Repairs legacy retention settings without discarding snapshot-history options.

## Updates

- Ignores AI-model and other non-application GitHub releases when checking for Picto updates.
- Continues to discover alpha releases so every current user can move to the newest available
  Picto build.
- Aligns the Windows installer filename with its update manifest so background updates can fetch
  the published installer successfully.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
