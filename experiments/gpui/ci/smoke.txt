# CI plays this script with the off-screen tool (src/offscreen.rs) and
# uploads the pictures it takes. The library is a generated one with 2,000
# items, which the example million_grid_demo makes.
#
# Pictures 01 to 08 are taken at 100% interface zoom:
#   01 the grid.
#   02 the grid with the pointer over a tile.
#   03 the grid scrolled down.
#   04 the viewer with an item open.
#   05 the context menu of an item.
#   06 the window's close button with the pointer over it. The app draws
#      this button only on Windows and Linux.
#   07 the application menu. The app draws this menu in the window only on
#      Windows and Linux.
#   08 the Settings window.
#
# Pictures 09 and 10 are taken at 150% interface zoom: the grid, and the
# context menu of an item. The menu is opened by a press at a position in
# window points, which checks that the press reaches the tile that is drawn
# at that position.
#
# Pictures 11 and 12 are taken at 80% interface zoom: the grid, and the
# Settings window, which is still open and takes the same zoom.
#
# Pictures 13 to 16 show the Subscriptions screen with one subscription that
# the script creates. The subscription has one source. The script never runs
# it: nothing presses Run, and the pointer is only moved, never pressed, on
# the source's row.
# They show that the screen's buttons in the titlebar do not overlap the
# window's own buttons:
#   13 the list of subscriptions.
#   14 the page of the subscription, with its rail. The pointer is on the
#      Edit button of the source's row. The picture shows that the row's
#      buttons stay visible while the pointer is on one of them, and that
#      they are drawn at full strength.
#   15 the same page with the rail hidden.
#   16 the same page at 150% interface zoom, where the titlebar buttons show
#      only their icons.
#
# Pictures 17 and 18 show the Duplicates screen after a scan, at 100% and at
# 125% interface zoom. The generated library has no two images that match,
# so the scan finds no pairs and both pictures show the screen's empty
# state ("No duplicate pairs"). The screen with a pair on it is therefore
# not photographed in CI.
#
# Pictures 19 to 21 show the Quick Search panel at 100% interface zoom. The
# script first opens the All destination and resets the zoom.
#   19 the panel just after its shortcut opened it (Command+T on macOS,
#      Control+T on Windows and Linux), with the search field empty.
#   20 the panel after the script typed "inbox". The list holds the
#      command and the place with that name.
#   21 the Inbox, which the script opened by pressing Enter on the first
#      row, the command Inbox. The picture shows that the panel has closed
#      and that the Inbox is open.
