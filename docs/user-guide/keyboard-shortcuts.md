# Keyboard Shortcuts

[← User Guide](README.md)

Complete reference of all keyboard shortcuts in Picto. `Mod` means `Ctrl` on Windows/Linux or `Cmd` on macOS.

## Navigation

| Shortcut | Action |
|----------|--------|
| `Mod+1` | All Active view |
| `Mod+2` | Inbox view |
| `Mod+3` | Untagged view |
| `Mod+4` | Trash view |
| `Mod+F` | Search / focus search bar |
| `Mod+K` | Command palette |
| `Mod+J` | Go to folder (quick-jump) |
| `Alt+Left` | Go back in history |
| `Alt+Right` | Go forward in history |

## File Operations

| Shortcut | Action |
|----------|--------|
| `Mod+I` | Import files |
| `Mod+E` | Export originals |
| `Mod+Shift+E` | Export as (convert format) |
| `Mod+Backspace` | Delete selected files |
| `Shift+Enter` | Open with default application |
| `Mod+O` | Open in new detail window |
| `Mod+Enter` | Reveal in Finder / Explorer |
| `Mod+,` | Open settings |
| `Mod+Shift+N` | New folder |
| `Alt+N` | New subfolder |
| `Mod+Shift+Alt+N` | New smart folder |
| `Mod+Shift+J` | Add to folder (picker) |
| `Shift+D` | Add to last-used folder |
| `Mod+Shift+Backspace` | Remove from current folder |
| `Mod+Shift+T` | Regenerate thumbnail |

## Edit

| Shortcut | Action |
|----------|--------|
| `Mod+Z` | Undo |
| `Mod+Shift+Z` | Redo |
| `Mod+A` | Select all |
| `Mod+Alt+C` | Copy file path |
| `Mod+Shift+C` | Copy tags |
| `Mod+Shift+V` | Paste tags |
| `T` | Add tags to selection |
| `F` | Add to folder |
| `Ctrl+R` | Rename file |
| `Mod+Shift+R` | Batch rename |

## Rating

| Shortcut | Action |
|----------|--------|
| `0` | Clear rating |
| `1` | Rate 1 star |
| `2` | Rate 2 stars |
| `3` | Rate 3 stars |
| `4` | Rate 4 stars |
| `5` | Rate 5 stars |

Applies to all selected files.

## Grid Navigation

| Shortcut | Action |
|----------|--------|
| `Arrow Left` or `A` | Move left |
| `Arrow Right` or `D` | Move right |
| `Arrow Up` or `W` | Move up |
| `Arrow Down` or `S` | Move down |
| `Home` | First image |
| `End` | Last image |
| `Page Up` | Page up |
| `Page Down` | Page down |

## Video Playback

| Shortcut | Action |
|----------|--------|

| `Arrow Up` | Volume up |
| `Arrow Down` | Volume down |
| `M` | Toggle mute |
| `L` | Toggle loop |
| `]` | Increase speed |
| `[` | Decrease speed |
| `Backspace` | Reset speed to 1x |

| Shortcut | Action |
|----------|--------|

| `Backspace` | Reject (move to trash) |
