# Picto User Guide

Picto is a desktop library for images, video and other media. It runs on Windows, macOS and Linux.

In this guide, `Mod` means `Ctrl` on Windows and Linux and `Cmd` on macOS. The complete, current
list of keyboard shortcuts is in **Settings → Shortcuts**, where you can also change them.
