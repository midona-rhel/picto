# Picto 0.6.11-alpha

* Improved the performance of the grid. There should be less flashing and smoother scrolling throughout the library.
* Images now load sharp, full-quality previews after remaining on screen, while fast scrolling avoids unnecessary work.
* Quick Look and detail views now open immediately and behave consistently across file types.
* Flash files now appear correctly in All and in file-type filters.
* Flash files now play correctly and remain contained within the viewer without stretching.
* Video, audio, and Flash controls now fade away while idle and return when you move the pointer or use playback controls.
* WebM videos now play reliably.
* After an update, Picto now shows what changed when it starts again.
