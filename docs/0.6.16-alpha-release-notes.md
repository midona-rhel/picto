# Picto 0.6.16-alpha

* Faster searching, sorting, and folder navigation in large libraries, with less background work while idle.
* More responsive imports, tagging, collection edits, and undo, especially in libraries with many tags and smart folders.
* Fixed range selection across unloaded items and kept selection highlights in step when the grid changes.
* Improved drag and drop, folder reordering, keyboard navigation, and inspector stability during undo and redo.
* In a folder, Cmd+Delete on macOS or Ctrl+Backspace on Windows and Linux now removes selected items from that folder without trashing them or removing them from other folders. Custom shortcut bindings remain supported.
* More reliable library opening, switching, and cancellation, with clearer progress and recovery from failed opens.
* Move, locate, or delete closed libraries from Library Manager. Watched folders can import into Inbox or directly into the active library.
* Fixed clearing item notes, smart-folder preview error handling, and restoring rules when cancelling an edit.
* Fixed experimental cloud-sync setup and improved recovery of interrupted imports.
* Picto Pack imports preserve existing undo and redo history when restoring metadata.
* Updated the user guide to match the current application.

The first open after upgrading backs up and updates supported older libraries. Preparing the updated library and its indexes can take extra time, especially for large libraries. Updated libraries may not open in older Picto versions.
