# Picto 0.6.6-alpha

Picto 0.6.6-alpha repairs tag and smart-folder filtering, makes Twitter subscriptions resilient to
live timeline changes, and strengthens portable-library imports and thumbnail recovery.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Filters and smart folders

- Validates cached tag membership and smart-folder results against the canonical library database
  when a library opens, rebuilding stale projections instead of temporarily returning an empty
  grid.
- Keeps searched tag-filter selections on the same tested filtering path as ordinary tag choices.
- Sorts tag searches alphabetically before pagination, so short and common matches are no longer
  hidden behind older or longer tag names.
- Sorts folder and smart-folder search results alphabetically while retaining the ancestors needed
  to understand their hierarchy.
- Keeps the filter bar aligned with the stored sidebar and inspector boundaries when either panel
  is hidden, matching the stable title-bar geometry without constraining the grid itself.

## Subscriptions

- Resumes Twitter / X media timelines by the next post's stable identity instead of assuming a live
  timeline page still has the same array indexes after each post settles.
- Falls back safely when X removes an expected post and accepts cursors written by earlier alpha
  releases, avoiding intermittent subscription failures when timelines are inserted, reordered, or
  shortened.

## Imports and thumbnails

- Runs Picto Pack imports on a dedicated safe-stack worker so large portable libraries cannot
  overflow Electron's native request thread.
- Preserves imported folder identities and makes repeated Picto Pack imports reconcile existing
  folders instead of duplicating them.
- Generates a missing raster thumbnail directly outside the media-protocol response, then notifies
  the renderer when it is ready, preventing thumbnails from remaining stuck behind a stale queued
  request.
- Removes the superseded thumbnail-queue command and generated response type.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
