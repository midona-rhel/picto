# Cloud sync played end to end by the off-screen tool against a folder that
# stands in for a Dropbox desktop folder (PICTO_DROPBOX_ROOT); no provider
# or account is contacted. The CI step fills in __LIBRARIES__ (the test
# libraries folder), __CLOUD__ (the stand-in folder, JSON-escaped) and
# __IMAGE1__…__IMAGE3__, then checks the printed answers: a library made
# here syncs, a snapshot is taken, a folder made after it is undone by
# restoring it from Settings › Cloud (the library is closed, its database
# replaced and opened again, which fails on Windows if this app still
# holds a connection to it), and the sync is stopped.
