# Collections

[← User Guide](README.md)

A collection (also called a group) keeps several media items together as one item in the grid, for
example the pages of a comic or the images of one post. A collection has a name, notes, a cover,
and its own member order. Tags, folders, rating, and Inbox/Trash state apply to the collection as a
whole.

## Create a collection

1. Select two or more items in the grid.
2. Right-click → **Group...**.
3. Enter a name and, optionally, **Collection notes**, then click **Create Group**.

The first selected item in grid order becomes the cover.

Collections are also created when you import several files and answer **Yes** to
**Import as Collection?** (see [Importing Files](importing-files.md#several-files-at-once)), and by
[subscriptions](subscriptions.md) that group multi-media posts.

### Add items to an existing collection

Select the collection together with the items to add and choose **Group...**. If the selection
contains several collections, choose **the group to keep**: it keeps its name, cover, order,
folders, and state, and every other selected item is appended to it. Click **Merge Groups**.

## View a collection

Double-click a collection or press `Enter`. Its members are shown one under another in a reader.

- Double-click a member to open it in the media view.
- `Left` / `Right` move to the previous / next item in the grid.
- `Escape` closes the reader.
- **Open in New Window** (`Mod+O`) opens the collection in its own window.

## Edit a collection

Right-click the collection → **Edit Group**, or click **Edit group** in the title bar while reading
it. The editor shows the members as a grid.

| Task | How |
|------|-----|
| Reorder members | Drag tiles to a new position. |
| Sort members | Right-click → **Sort by** → Name or Size. |
| Detach members | Select them and press `Delete` or `Backspace`, or right-click → **Remove from Group**. They return to the library as separate items. |
| Trash members | Right-click → **Move to Trash**. They leave the collection and go to Trash. |
| Open a member | Double-click it; `Space` opens Quick Look. |

`Escape` clears the selection, then leaves the editor.

## Ungroup

Right-click the collection → **Ungroup...** (or right-click empty space inside it) and confirm.
Every member returns to the library as a separate item. No files or metadata are deleted.

All collection changes can be undone with `Mod+Z`.
