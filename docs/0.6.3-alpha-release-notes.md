# Picto 0.6.3-alpha

Picto 0.6.3-alpha is a focused reliability release for updates, duplicate review, and large AI
tagging jobs.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Updates and release delivery

- Checks for new versions even when no library is open, so an older installation can offer the
  newest alpha immediately after startup.
- Ensures tagged release builds attach their macOS, Windows, and Linux packages to the GitHub
  release after all platform smoke tests pass.
- Keeps debugger-only metadata out of packaged applications.

## Duplicate review

- Uses an explicit, evidence-based smart-merge quality order instead of favoring a candidate merely
  because it appears on the left.
- Uses file size as the final tie-break only after stronger image-quality evidence is equal.
- Documents the quality signals and difference-view expectations used to evaluate future duplicate
  scoring changes.

## AI tagging

- Allows AI tagging to resolve mixed and route-wide selections, including unloaded Ctrl+A results,
  while processing only taggable images.
- Streams large jobs one image at a time instead of preparing the entire selection before inference.
- Keeps only a small review window resident, prefetches the next batch, retains completed
  predictions, and stops scheduling work when the AI tag portal closes.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
