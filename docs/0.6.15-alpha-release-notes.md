# Picto 0.6.15-alpha

* More reliable subscription history loading, including OnlyFans timelines with gaps between available posts.
* Subscription limits include skipped posts, and a limited run no longer appears to have exhausted the source.
* Completion notifications count new library items, with each collection counted once instead of counting its individual downloads.
* Improved source compatibility, original-media selection, login scoping, and handling of service rate limits.
* Updated automatic-update dependencies with security fixes.
* Smoother fast scrolling, with thumbnail reveals starting within 500 pixels of the viewport while keeping the consistent 100 ms delay and 500 ms fade.
* Fixed blank grids after development hot reload and errors caused by cancelled scrolling requests.
* Restored normal macOS Dock and app-switcher visibility during development.

The first open after upgrading creates a library backup and updates the library format. Updated libraries may not open in older Picto versions.
