# Picto 0.6.8-alpha

Picto 0.6.8-alpha repairs duplicate General tags, strengthens library creation safety, and improves
cloud-restored thumbnail recovery and progress reporting.

This remains an alpha release. Keep an independent backup of important libraries, especially when
using the same cloud-backed library from more than one computer.

## Tags and AI tagging

- Merges the redundant explicit `general` tag group into Picto's canonical unnamespaced General
  group when a library opens, preserving and combining every media assignment.
- Prevents AI review, background AI tagging, subscriptions, imports, tutorials, tag editing, and
  other tag-writing paths from recreating separate `general:tag` identities.
- Prevents duplicate paginated tag-search results when multiple page requests overlap or an older
  search response arrives late.

## Libraries and cloud recovery

- Rejects local and cloud library destinations located inside another `.library` package on every
  supported platform.
- Presents blocking cloud restoration in a focused progress dialog and keeps non-blocking cloud
  work in a stable bottom progress bar without reflowing the workspace.
- Queues missing thumbnail work when restored original blobs become available and streams completed
  thumbnails into the open grid.
- Keeps thumbnail frame scheduling bound correctly so progressive thumbnail updates continue while
  the application is running.

## Build reliability

- Reduces redundant CI verification and uses current GitHub Actions runtimes.
- Supplies the packaged FFmpeg runtime to Rust integration tests that require media probing.

## Packages

- macOS Apple Silicon: DMG and ZIP
- Windows x86-64: NSIS installer
- Linux x86-64: AppImage

Intel macOS is not supported. The macOS alpha is self-signed rather than Apple-notarized, so its
update notification links to the new download. Windows and Linux builds support the in-app update
flow.
