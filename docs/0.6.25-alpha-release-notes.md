# Picto 0.6.25-alpha

* The first video that you open after Picto started no longer shows its first frame about a second later than the following videos. Picto now starts its two video programs once in the background when it starts.
* **Delete Cloud Data…** says why it removed nothing. When the file `library.json` in the library's cloud folder cannot be read, the message says so and asks you to check that the desktop app of the cloud provider is running. Before, it said that the cloud folder did not hold the library's data.
* The log window shows the time that a command itself took. A command that was sent while the library was still opening was shown with the time of the opening added, about one second each.
